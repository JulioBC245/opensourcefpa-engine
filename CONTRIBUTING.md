# Contributing

Thank you for helping improve the OpenSourceFPA engine.

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Never commit real company data, accounting exports or API keys. Use the fictional fixtures in `data/fixtures/`.
3. Run `Rscript tests/run-all.R` before opening a pull request.
4. Keep the licence header at the top of every R file.
5. By opening a pull request, you confirm that you have read and accept the [Contributor Licence Agreement](CLA.md). Add this line to your first pull request description: "I have read the CLA and I accept it."
